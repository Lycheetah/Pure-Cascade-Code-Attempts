### Basic Usage

```python
from cascade_core import KnowledgePyramid, KnowledgeBlock, Layer

# Create pyramid
pyramid = KnowledgePyramid("my_domain")

# Add foundation
foundation = KnowledgeBlock(
    content="Energy is continuous",
    evidence_strength=0.90,
    layer=Layer.FOUNDATION
)
pyramid.add_foundation(foundation)

# Add paradigm-shifting information
quantum = KnowledgeBlock(
    content="Energy is quantized",
    evidence_strength=0.98,
    layer=Layer.FOUNDATION,
    contradicts=[foundation]
)

# Automatic cascade reorganization
report = pyramid.add_knowledge(quantum)
print(report.summary())
```

### Sovereign Interface

from cascade_core import SovereignInterface
